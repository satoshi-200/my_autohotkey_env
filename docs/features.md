# 機能の説明

`README.md` から分けた、機能・モードの使い方の説明。**キーごとの割り当ての一覧は、ここには書かない**（変えるたびに古くなるため）。
割り当ては、画面（クイックメニュー S → K = Caps → j → s → k）か、`keymap/` のファイル（行末のコメント）を見る。
作りや約束事は `development.md`、判断の基準は `principles.md`。

## 入力待ち（`keymap/leader_keys.ahk`）
起点のキー（Caps、Space+F、Space+A）を押して離すと「次のキー待ち」になり、次に押したキーで機能が分かれる。
- 待っている間は、マウスカーソルのそばにモードの名前をツールチップで表示する。
- 1 秒間何も押さないと、そのモードの割り当て一覧を表示する（`LEADER_HELP_DELAY_MS`）。説明には割り当て表の行末コメントを使う。
- **Esc**、**CapsLock**、**Space+CapsLock** でキャンセル。10 秒間何も押さないと自動でキャンセル（`Lib/key_wait.ahk` の `IH_TIMEOUT_SEC`）。
- 待っている間は、ほかのレイヤーのホットキーを無効にする。
- 割り当ては各関数（`Leader_Caps()` など）の表に「キー, 送るキーまたは関数」の形で書く。`""` は未割り当て（特殊キーも `""` にできる）。

起点ごとの役割：
- **Caps →**：メニュー・モードの入口（コマンドパレット、クイックメニュー、記号メニュー、画面キャプチャ、アプリ切り替え、タブ・ページ切り替え、ウィンドウのモニター移動、仮想デスクトップ、Fn / Ctrl+数字の入力、Alt / Ctrl / Win + 文字、ドラッグ、Vimium C 風ヒント、Shift 長押しモード、次の 1 文字を大文字、など）。
- **Space+F →**：カーソルの大きな移動（文書の先頭・末尾、行頭・行末）、日付の入力、修飾キーの単押し、右クリックメニュー、ウィンドウを閉じる、再読み込み。
- **Space+A →**：右手側の文字・記号を左手で入力する（Shift 長押しモード中も使え、送る文字に Shift が反映される）。

## 3 キー・短押し（`keymap/hold_keys.ahk`、`chord_keys.ahk`、`chord_ordered_keys.ahk`）
- **短押し**：変換・無変換・Space を単独で押して離したときに働く（元のキーの働きは置き換わる）。`*vk20::` なので、Shift+Space・Ctrl+Space もそのまま通る。
- **3 キー**：変換と無変換を両方押したままさらに別のキー。押す順番を区別する（変換 → 無変換 は `chord_keys.ahk`、無変換 → 変換 は `chord_ordered_keys.ahk`）。両方を押している間は、通常の割り当てが止まり、書いたキー以外は何も起きない。
- 仕組みと注意は `development.md` の「3 キーの割り当て」。

## アプリ切り替え（Caps → e、`Lib/window_switch.ahk`）
- Alt+Tab の一覧を出したままにする（Alt を押し続ける必要はない）。
- 続けて `e` で次、`w` で前のアプリを選ぶ。`j k l ;` または `a s d f` で ← ↑ ↓ → に動かす。
- Delete で選んでいるウィンドウを閉じる。
- 変換・Enter などのキーを押すか、3 秒操作しないと決定（`APPSWITCH_IDLE_SEC`）。Esc / CapsLock でキャンセル。
- Space を押したままなら、他のモードと同じ：Space+`j k l ;` で ← ↑ ↓ →、Space+`g` / `h` で決定、Space+Caps でキャンセル。
- Caps → e だけなら、直前に使っていたアプリに切り替わる。

## Vimium C 風ヒント（Caps → Caps、`Lib/vimium_c_hints.ahk`）
- ブラウザ拡張 Vimium C のリンクヒントと同じ操作を、デスクトップのアプリで使えるようにしたもの。
- いまのウィンドウの操作できる部品（ボタン・タブ・入力欄・リスト項目など）に英字のラベルを重ねて表示し、ラベルを打つとそこをクリックする。ラベルは 1〜2 文字で、打つごとに候補が絞られ、BackSpace で 1 文字戻せる。
- ラベルを左手だけで入力できる。Space+A のあとに打つキー 1 つが、Space+A の表で右手側の文字になる（Q → P、S → L など）。変換+g や Space+s（BackSpace）も、モードの中で BackSpace として効く。
- 旧の動作（ラベルを打つ前に親指キーを短く押して、クリックの種類を変える）は、`VIMIUMC_THUMB_CLICK` を `true` にすると戻る（そのとき Space+A の左手入力は使えない）。
- Tab で対象を「ウィンドウ ↔ タスクバー」に切り替える。Caps で右クリックに切り替える。左 Shift でカーソル移動モードへ切り替える。
- Esc / Space+Caps でキャンセル。10 秒間何も押さなくても自動でキャンセル。
- 案内は、押したい部品を隠さないようにモニターの左下に短く出し、1 秒手が止まると操作の説明も出す（`VIMIUMC_TIP`。カーソル移動モードは `MOUSEGRID_TIP`）。
- 部品の取得には UI Automation を使うので、アプリによって取れる部品が違う。Web ページの中身は対象外（ブラウザは拡張機能を使う）。初めて開くアプリは数秒かかることがある。

## カーソル移動モード（Vimium C 風ヒントの表示中に左 Shift、`Lib/mouse_grid.ahk`）
- キーボードの配置（`q`〜`p` / `a`〜`;` / `z`〜`/` の 10 × 3）を画面の地図にして、打ったキーの位置へカーソルを飛ばして終了する（1 階層。`MOUSEGRID_MAX_DEPTH` を 2 にすると、そのマスの中へもう 1 回絞り込める）。
- BS：1 段戻る、Space+A → キー：左手だけで右手側のマスを指す、Tab：領域を替える（モニター・ウィンドウ）、半角/全角：開始位置へ戻る、Esc / Caps / Space+Caps / かな：終了。赤ポチを動かすか、ボタンを押すと自動で終了する。

## Fn キー / Ctrl ＋ 数字キー入力モード（Caps → f、`Lib/oneshot_modifiers.ahk`）
左手で F1〜F12、右手で Ctrl+1〜8 を入力する。配置：
```
q:F12  w:F7  e:F8  r:F9      u:Ctrl+5  i:Ctrl+6  o:Ctrl+7  p:Ctrl+8
a:F11  s:F4  d:F5  f:F6      j:Ctrl+1  k:Ctrl+2  l:Ctrl+3  ;:Ctrl+4
z:F10  x:F1  c:F2  v:F3
```

## Shift 長押しモード（Caps → Space、`Lib/shift_hold.ahk`）
- 入ると Shift を押したままの状態になり、終わるまで、Shift を押しながら打つのと同じ入力になる（英字は大文字、数字・記号は Shift 側）。
- モード中は、前面のウィンドウのあるモニターの上端に色つきの帯と、左下にツールチップを出す（`SHIFTHOLD_BAR_HEIGHT` / `SHIFTHOLD_BAR_COLOR`）。
- 終了：Esc / Caps / Space+Caps、変換・無変換の短押し、一定時間の無操作。Enter は、IME が日本語入力のときは確定してモードを抜け、半角英数のときは 1 回目はモードを抜けるだけ（2 回目から普通の Enter）。

## 直前の入力（`Lib/last_input.ahk`）
- 無変換 + m：直前の 1 文字（記号など）をもう一度入力する。キーを打った文字は IME オンでも覚え、変換・無変換・Space のレイヤー、Space+A → キー、記号メニューで入力した文字も覚える。全角・半角は画面に出た形のまま入力する。

## クイックメニュー / Quick Menu（`Lib/quick_menu.ahk`）
よく使う機能を、一覧から選んで実行するランチャー。
- **クイックメニュー**（Caps → j）：英字 1 文字でカテゴリを選び、もう 1 文字で実行する。
- **コマンドパレット**（Caps → u）：英名や日本語で絞り込んで実行する。
- **記号メニュー**（Caps → k）：記号の英語名の頭文字で記号を入力する。IME の状態に合わせて全角・半角を切り替える。既定はツールチップ表示（Space：全角／半角、Esc / Caps：閉じる）。`QM_SYMBOL_UI` を `"window"` にすると小窓になる。

| カテゴリ | 主な機能 |
| :--- | :--- |
| T テキスト変換 | 大文字・小文字、全角・半角、ひらがな・カタカナ、改行の削除、並べ替え、重複行の削除 など |
| I 挿入 | 記号メニュー |
| N 日付・時刻 | 日付を選んで入力（N → N：日付を調整 → 確定 → フォーマットを選ぶ。Space+F → i でも直接呼べる。`Lib/date_input.ahk`）、日付・日時・時刻、曜日付き、ファイル名用の書式（Space+F → u で直接開く） |
| W ウィンドウ | 最前面、半透明、中央へ移動、ウィンドウ情報のコピー |
| D 仮想デスクトップ | 作成・削除、前後への切り替え、ウィンドウを連れて移動（Caps → w で直接開く） |
| G 検索・翻訳 | Google 検索、日本語・英語への翻訳 |
| S システム | クリップボード履歴、画面キャプチャ、PC のロック、画面を消す、再読み込み、キー割り当て・設定（S → K。キーをクリックすると行を書き換えて保存でき、「設定」タブで設定値も変えられる。保存前に構文を確認し、1 つ前の内容に戻せる。反映は Insert のあと） など |
| C 画面キャプチャ | 範囲指定（ドラッグ）、端を自動トリミング（C → T。設定は `Lib/screen_capture.ahk` 冒頭の `CAP_TRIM_*`）、ウィンドウを選んで全体、ウィンドウ内のクリックした領域（K / ホイール↑で外側、L / ホイール↓で内側）。Caps → t で直接開く。PNG 保存＋クリップボードにコピー |
| M マルチクリップボード | 箱にコピー保存・切り取り保存、箱から貼り付け、中身を見る、空にする |
| A アプリ・フォルダ | ダウンロード、スクリプトのフォルダ、VS Code、メモ帳、電卓、Windows の設定 |
| V VS Code | 折りたたみ・展開 |
| O Office | 図形編集モード（F。PowerPoint・Word・Excel で選択中の図形を、ホームポジションのまま動かす・大きさを変える・回転する。Word は浮動図形のみ）。アプリ専用の機能は、前面のアプリの分だけ出る（`Lib/office_common.ahk`、`Lib/powerpoint_pack.ahk`） |

Esc・CapsLock・ほかの場所のクリックで閉じる。機能の追加方法は `development.md` と `Lib/quick_menu.ahk` 冒頭のコメント。
