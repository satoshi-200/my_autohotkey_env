# アイデア（未実装）

PC 作業全般を高速化するための、アプリに依存しない汎用的な機能のアイデア。
判断の基準は `principles.md`。キーの割り当ては未定（実装するときに決める）。
実装したものの設計の経緯・案の比較は `archive/ideas_history.md`（Vimium C 風ヒント、カーソル移動モード、Shift 長押しモード、キー割り当ての編集、画面キャプチャの自動トリミング、PowerPoint の詰め合わせ）。

## 小さいが毎日効きそうなもの
- 打ち間違いの直し：直前に打った単語を、IME のオン・オフを逆にして打ち直す。CapsLock の誤爆（`hELLO`）も直す。
- マイクの全体ミュート：アプリに関係なく 1 打鍵でミュートし、状態を常に見えるようにする。
- アプリごとの IME 状態の記憶：アプリごとに前回の IME の状態を覚えておき、切り替えたときに自動で戻す。
- すぐメモ：小さな入力欄を出して 1 行書き、Enter でファイルの末尾に追記して閉じる。

## 変わり種
- 画面の変化待ち：画面の範囲を指定し、そこが変わったら通知する（ビルド、ダウンロード、レンダリングの完了待ち）。
- 窓のライブ縮小表示：別の窓の一部分を、小さな常時表示のウィンドウとして画面の隅に出す（DWM の仕組みを使う）。
- キー使用統計：どのキーをどれだけ使ったかを記録し、使われていない割り当てや、よく使うのに遠い割り当てを見つける。
- 作業ログ：アクティブなウィンドウのタイトルを時間とともに自動で記録し、後から検索できるようにする。
- 集中モード：アクティブなウィンドウ以外を暗く覆う。

## 割り当ての空き（親指キーまわり）
- 変換 → 無変換 / 無変換 → 変換 の 3 キー（`keymap/chord_keys.ahk`、`chord_ordered_keys.ahk`）：空いているキーがまだ多い。Enter 系は Shift / Ctrl / Alt / Ctrl+Shift が済み。未割り当ての組み合わせの候補：Ctrl+Alt+Enter、行末へ移動してから Enter。
- 2 キー自体（無変換 → 変換、変換 → 無変換）に処理を割り当てるときは `Chord_Begin(順, 関数)`（`Lib/chord.ahk`）。ただし 3 つ目のキーを押す前に働く。

## 優先度の見立て
- 実装が軽く、効果がすぐ出るのは 2（OCR）・3（計算）・4（窓ハープーン）。最初に手を付けるならこの 3 つ。
- 5・6 は使う場面が決まっているが、効く場面では非常に効く。
