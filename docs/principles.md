# 方針

PC 作業全般を高速化するための、アプリに依存しない汎用的な機能を作るときの基準。
機能を足す・キーを割り当てるときは、まずここを見る。

作成日：2026-10-08

## 基本方針
- 特定のアプリに依存せず、どのアプリでも使えること。
  - アプリごとの個別対応（特定アプリ向けの分岐やチューニング）は作り込まない。OS の標準の仕組み（UI Automation など）で足りない箇所は、操作で補う（例：親をたどるキー）。
- ホームポジションを崩さないこと。Shift / Ctrl / Alt の同時押しや、手を大きく動かす操作は避け、ホームポジションのキーと親指キー（Space・変換・無変換）で完結させる。
- 今足りない 3 つの領域を埋める。
  - 画面の中の対象を、キーボードだけで操作する
  - 画面や選択の中身を取り出して加工する
  - 作業の文脈（ウィンドウの配置、何をしていたか）を覚えておく

## キー割り当ての考え方（地価）
- キーの「地価」は、ホームポジションからの近さで決める。指を動かさずに押せるほど高い。
  - 最高：親指キー（Space・変換・無変換）、ホーム段（`a s d f` / `j k l ;`）。
  - 高い：最高のキーから指を少し伸ばせば届くキー。
    - ホーム段の端・隣：`CapsLock`、`g` `h`、`:`
    - 上段で人差し指・中指・薬指が届くもの：`w e r` / `u i o` など
  - 低い：数字列、下段（`z x c v b n m , . /`）、端のキー（`\` `^` `]` など）、手を大きく動かすキー。
- 空いている高地価のキーは数が少ない。使う頻度が高く効果が大きい機能から順に、地価の高い空きへ置く。
- 頻度の低い機能は、低地価のキーかクイックメニューに回す。高地価の空きを使わない。
- 同じ地価なら、押す回数が少ない割り当ての方が高い（同時押し・単打 ＞ 入力待ちの 2 打鍵目）。
