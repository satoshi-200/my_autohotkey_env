# My AutoHotkey Environment (Main Script)

## 概要 / Description
私のメインPCで使用している AutoHotkey v2 用のメインスクリプトです。
ホームポジションから手を動かさずに、あらゆる操作（マウス操作、記号入力、ウィンドウ管理、日付入力など）を完結させることを目的としています。

## 動作環境 / Environment
- Windows
- AutoHotkey v2.0 以上
- 日本語 JIS 配列キーボード

## 使い方 / Usage
1. `main.ahk` を実行する（ほかのファイルは `main.ahk` から読み込まれる）。
2. 設定を変えたら **Insert** キーで再読み込みする。

## キー対応表 / Key Reference
スクリプト内では、特殊キーを次のコードで書いています。

| コード | キー |
| :--- | :--- |
| `vk1C` | 変換 |
| `vk1D` | 無変換 |
| `vk20` | Space |
| `sc03A` | CapsLock |
| `sc070` | カタカナひらがな |
| `sc00F` | Tab |
| `sc029` | 半角/全角 |

ほかのキーコード（テンキーなど）は `Lib/config.ahk` の早見表を参照。

## レイヤー構成 / Layers
「キーを押しながら別のキー」で使うレイヤーと、「押して離してから次のキー」で使う入力待ちの 2 種類がある。
代表的なものだけを挙げる。すべての割り当ては `keymap/hold_keys.ahk` と `keymap/leader_keys.ahk` を参照。

### 押しながら使うレイヤー（`keymap/hold_keys.ahk`）
| 起点 | 主な機能 |
| :--- | :--- |
| **変換** | Delete / BackSpace、元に戻す / やり直し、括弧などの記号、テンキー（数字・計算記号） |
| **無変換** | マウスカーソルの移動・ジャンプ・モニター間の移動、スクロール、クリック、アプリ切り替え（Alt+Tab）、ウィンドウの最大化・最小化、記号、箇条書き |
| **Space** | カーソル移動（矢印・Home/End・単語単位）、Enter、Tab / F6 でのフォーカス移動、F2、Escape（Space+Caps）、タブ・ページ移動、スクロール、クリック、入力待ちの呼び出し（Space+F / Space+A） |

### 入力待ち（`keymap/leader_keys.ahk`）
起点のキーを押すと「次のキー待ち」になり、次に押したキーで機能が分かれる。

| 起点 | 内容 |
| :--- | :--- |
| **CapsLock** | 下の表を参照 |
| **Space + F** | 文書の先頭 / 末尾・行頭 / 行末への移動、修飾キー付き Enter、日付の入力、Win / Alt / Ctrl キー、ウィンドウを閉じる |
| **Space + A** | 右手側の文字・記号を左手で入力する |
| **カタカナひらがな** | 遠いキー（y / u / o / p）を近いキーで入力する |

**CapsLock → 次のキー**
| キー | 機能 |
| :--- | :--- |
| `u` | コマンドパレット |
| `k` | クイックメニュー |
| `j` | 記号メニュー |
| `y` | よく使う Web ページ（クイックメニューの B カテゴリ） |
| `e` | アプリ切り替え（下の説明を参照） |
| `w` | 仮想デスクトップメニュー |
| `d` | タブ・ページ切り替え（f / a：次 / 前のタブ、d / s：次 / 前のページ。w / t / r：タブを閉じる / 新しいタブ / 閉じたタブを復元。右手は j / ;：前 / 次のタブ、k / l・i / o：前 / 次のページ。連打で移動、ほかのキーで決定、Esc / Caps で元に戻る） |
| `r` / `Tab` | ウィンドウを別のモニターへ移動（同じキーで次、Shift 付きで前。カーソルも移動先の中央へ） |
| `q` | ウィンドウの大きさ（w：Win+↑ / e：Win+↓。連打可。ほかのキーで決定、Esc / Caps で元に戻る） |
| `f` | Fn キー入力モード（下の配置で F1〜F12） |
| `l` / `o` / `i` / `;` | Ctrl / Ctrl+Shift / Alt / Win ＋ 文字キー |
| `.` / `,` | Ctrl ＋ 数字キー（左手で入力。w e r：7 8 9 / s d f：4 5 6 / x c v：1 2 3 / z：0） |
| `v` / `z` / `c` / `x` | 未割り当て |
| `b` / `\` | マルチクリップボード（確認 / 全消去） |
| `n` | 次に打つ文字を大文字にする |
| `g` / `h` | Enter |
| `Space` / `変換` | IME を半角 / ひらがなにする |

Fn キー入力モードのキー配置：
```
q:F12  w:F7  e:F8  r:F9
a:F11  s:F4  d:F5  f:F6
z:F10  x:F1  c:F2  v:F3
```

アプリ切り替え（Caps → e）：
- Alt+Tab の一覧を出したままにする（Alt を押し続ける必要はない）。
- 続けて `e` で次、`w` で前のアプリを選ぶ。`j k l ;` または `a s d f` で ← ↑ ↓ → に動かす。
- Delete で選んでいるウィンドウを閉じる。
- 変換・Enter などのキーを押すか、3 秒操作しないと決定（`Lib/system_utils.ahk` の `APPSWITCH_IDLE_SEC` で変更可）。Esc / CapsLock / Space でキャンセル。
- Caps → e だけなら、直前に使っていたアプリに切り替わる。

**入力待ちの共通の動き**
- 待っている間は、マウスカーソルのそばにモードの名前をツールチップで表示する。
- **Esc**、**CapsLock**、**Space+CapsLock** でキャンセルできる。
- 5 秒間何も押さないと自動でキャンセルする（`Lib/key_wait.ahk` の `IH_TIMEOUT_SEC` で変更可）。
- 待っている間は、ほかのレイヤーのホットキーを無効にする。

## クイックメニュー / Quick Menu（`Lib/quick_menu.ahk`）
よく使う機能を、一覧から選んで実行するランチャー。
- **クイックメニュー**（Caps → k）：英字 1 文字でカテゴリを選び、もう 1 文字で実行する。
- **コマンドパレット**（Caps → u）：英名や日本語で絞り込んで実行する。
- **記号メニュー**（Caps → j）：記号の英語名の頭文字で記号を入力する。IME の状態に合わせて全角・半角を切り替える。

| カテゴリ | 主な機能 |
| :--- | :--- |
| T テキスト変換 | 大文字・小文字、全角・半角、ひらがな・カタカナ、改行の削除、並べ替え、重複行の削除 など |
| I 挿入 | 記号メニュー、日付・時刻 |
| W ウィンドウ | 最前面、半透明、中央へ移動、ウィンドウ情報のコピー |
| G 検索・翻訳 | Google 検索、日本語・英語への翻訳 |
| S システム | クリップボード履歴、画面キャプチャ、PC のロック、画面を消す、再読み込み など |
| A アプリ・フォルダ | ダウンロード、スクリプトのフォルダ、VS Code、メモ帳、電卓、Windows の設定 |
| B Web ページ | よく使う Web ページを開く（Caps → y で直接開く）。URL は `bookmarks.txt` に書く（git には含めない。書き方は `bookmarks.sample.txt` を参照） |
| V VS Code | 折りたたみ・展開（切り替え / 再帰的 / すべて） |
| F / H / C / X | F1〜F12 ／ Shift ／ Ctrl ／ Ctrl+Shift 付き |

Esc・CapsLock・ほかの場所のクリックで閉じる。機能の追加方法はファイル冒頭のコメントを参照。

## ファイル構成 / Structure
```
main.ahk                 入口（これを実行する）。読み込みと Insert での再読み込み
keymap/
  hold_keys.ahk          押しながら使うレイヤー（変換 / 無変換 / Space ＋ 何か）
  leader_keys.ahk        入力待ちの割り当て（Caps / Space+F / Space+A / かな → 次のキー）
Lib/
  config.ahk             動作設定（常駐・フック・優先度など）、共通の定数、キーコード早見表
  IME.ahk                IME の状態の取得・設定（外部から取得したライブラリ。変更しない）
  text_input.ahk         文字入力の補助（IME の切り替え、大文字化、日付の入力、ホイールでのテキストカーソル移動）
  key_wait.ahk           入力待ちの共通部品（待機中の表示、キャンセル・タイムアウト）
  oneshot_modifiers.ahk  次のキーを Fn / Ctrl / Alt / Win 付きで送る入力モード
  quick_menu.ahk         クイックメニュー・コマンドパレット・記号メニュー
  mouse_cursor.ahk       キーボードでのマウス操作（加速つきの移動、スクロール、ジャンプ、モニター移動）
  multi_clipboard.ahk    マルチクリップボード（キーごとに文字列を保存・貼り付け）
  system_utils.ahk       アプリの起動・切り替え、最前面固定、スクリーンセーバー回避
  archive/               使わなくなったスクリプトの保管場所（読み込まれない）
```
